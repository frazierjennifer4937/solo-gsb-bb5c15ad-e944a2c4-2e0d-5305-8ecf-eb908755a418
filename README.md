# 🥾 徒步轨迹遮蔽分享

一个轻量的徒步轨迹分享网页：上传**带时间信息的 GPX**后，在**无底图**的轨迹预览图上点击敏感地点并设置遮蔽半径；系统按**轨迹线段与遮蔽圆的交点**裁切轨迹（即使相邻采样点都在圆外，只要线段穿过圆也会被识别），交点时间按比例插值，最终导出**互不连接的多个 GPX `trkseg`**。页面展示隐藏段数、裁切前后距离与下载入口。

技术栈：**Python + FastAPI** 后端，**原生 JavaScript + SVG** 前端（无前端构建、无地图底图、无第三方 JS 库）。

## ✨ 功能

- 📤 上传含 `<time>` 的 GPX（多 `trkseg` 支持）
- 🗺️ 无底图 SVG 预览：网格背景、等距比例尺、鼠标经纬度读数
- ⭕ 点击添加遮蔽圆（靠近轨迹自动吸附），可拖动圆心、直接修改半径、单独删除
- ✂️ 线段–圆求交裁切：
  - 二次方程判别式检测，**两端点都在圆外但线段穿越**同样识别
  - 交点坐标在局部米制投影上插值，**时间按比例线性插值**，海拔同步插值
  - 保留原始分段边界，可见部分导出为**互不相连的 `trkseg`**（仅在圆边界相触的可见段也不会被连接）
  - 重叠遮蔽圆自动取并集
- 📊 显示隐藏段数、裁切前/后距离、移除距离及比例、导出分段数
- 💾 一键下载裁切后的 GPX
- 🐳 依赖安装在镜像构建时完成，初始化（建目录、健康检查）随容器启动完成

## 🚀 一条命令启动

```bash
docker compose up -d --build
```

启动后在浏览器打开：

**http://localhost:8000**

> 端口：容器内服务监听 **8000**；如要改宿主机端口，编辑 `docker-compose.yml` 中 `ports`，例如 `"9000:8000"` 后访问 http://localhost:9000 。

停止 / 查看日志：

```bash
docker compose down        # 停止
docker compose logs -f     # 查看日志
```

## ⚙️ 必要配置

所有配置均有默认值，零配置即可运行；如需调整，在 `docker-compose.yml` 的 `environment` 中修改：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8000` | 容器内监听端口（一般无需修改） |
| `DATA_DIR` | `/data` | 运行数据目录（命名卷 `trail-data` 持久化） |
| `SESSION_TTL_SECONDS` | `10800` | 上传轨迹会话保留时长（3 小时，存于内存） |
| `MAX_UPLOAD_MB` | `20` | GPX 上传大小上限（MB） |

**网页地址与端口**：`http://<宿主机IP>:<映射端口>`，默认即 **http://localhost:8000**。

## 🧭 使用步骤

1. 打开网页，选择 GPX 文件并点击「上传并预览」。
2. 在预览图上点击敏感位置（家、营地、藏车点等）添加遮蔽圆；拖动圆点调整位置，在右侧列表修改半径（米）或删除。可添加多个遮蔽圆。
3. 点击「应用裁切」：红色虚线为识别出的隐藏段，绿色为保留的可见轨迹。
4. 查看隐藏段数与裁切前后距离，点击「下载裁切后 GPX」。导出文件包含一条轨迹、若干互不连接的 `trkseg`，可直接分享或导入常用 GPX 工具。

## 📐 裁切与隐私说明

- 遮蔽单位是**以点击坐标为圆心、给定半径（米）的圆**；轨迹经过圆内的部分整体移除。
- 交点按线段与圆的真实几何交点计算，不依赖采样点密度，可避免“采样稀疏导致漏遮蔽”。
- 交点位置在赤道等距投影上生成，时间按弧长参数线性插值；请按实际定位误差适当加大遮蔽半径，本工具不构成匿名化保证。
- 轨迹数据保存在**单容器内存会话**中，到期自动清除；多实例/重启不会共享会话。

## 🛠️ 本地开发（不使用 Docker）

需要 Python 3.11+：

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
DATA_DIR=./data uvicorn app.main:app --reload --port 8000
```

打开 http://localhost:8000 。
